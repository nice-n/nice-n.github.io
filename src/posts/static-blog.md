> 这是一篇建站示例，介绍当前博客的实际技术方案。

这个博客使用 Eleventy 生成静态页面，文章保存在 Markdown 文件里，不依赖数据库。

## 从写作到发布

1. 在 `src/posts/` 添加文章。
2. 本地执行 `npm run dev` 预览。
3. 确认内容后，提交并推送到 GitHub 仓库。
4. GitHub Actions 安装依赖、运行检查、构建并部署到 Pages。

## 为什么先保持简单

对于以阅读和写作为主的博客，静态页面已经能满足大部分需求。它不需要维护服务端程序，也没有数据库迁移的负担。

代价是没有内置后台、登录和评论。如果以后确实需要，再单独评估，不把复杂度提前带进来。

## 发布前检查什么

- 把示例文章替换成自己的内容。
- 检查图片、链接与手机排版。
- 确认没有私密信息、公司内部资料和密钥。
- 发布后再次打开线上页面验证，不能把本地构建成功当成发布成功。
